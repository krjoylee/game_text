> **적용 대상**: 전체 문학 팩 (`packs/*`), 엔진 런타임 (`tools/build_master_game.py`), 씬 데이터 (`3_scene.yaml`)

## 1. 개요 및 배경 (Why This Spec Exists)

### 1.1 기존 단일 10점 만점제의 문제점
* 프로젝트 초기에는 모든 문학 작품이 7~10막 수준의 단편으로 기획되어 `시작 3점 / 최대 10점`이라는 고정 점수제가 적용되었습니다.
* 그러나 게임성과 완독감을 높이기 위해 **초급(10막), 중급(15막), 고급(20막)**으로 서사 길이가 대폭 확장됨에 따라, 긴 서사를 지닌 중급/고급 작품에서 기존 10점 제도를 유지할 경우:
  1. 중반부(7~8막)에 이미 점수가 10점에 도달하여 게이지 바가 꽉 차버림.
  2. 후반부(9~20막)에서 도덕적·철학적 고뇌의 선택을 내려도 점수가 더 이상 오르지 않아 긴장감이 소멸함.
  3. 분기 이벤트의 델타가 `+2`, `+3`, `-2` 등 비표준으로 부여되어 점수 상승선이 제멋대로 날뛰는 기획적 불일치 발생.

### 1.2 가변 점수제(Dynamic Metric Architecture)의 핵심 원칙
* **서사 길이(막 수)와 선택지 개수에 따라 맥스 점수(Max Score)가 유기적으로 연동**되어야 한다.
* **선택지 델타는 `±1 룰`로 표준화**되어 점수의 예측 가능성과 점진적 긴장감을 보장한다.
* **엔딩 판정 컷오프는 획득 가능한 이론상 최대 점수의 백분율**로 엄격하게 비례 산출한다.

## 2. 난이도별 3대 서사 등급 및 점수 수학 공식

### 2.1 기본 계산 공식
$$ \text{Max Score} = \text{Initial Score (3)} + \text{Total Choice Scenes} $$
$$ \text{Min Score} = \max(0, \text{Initial Score (3)} - \text{Total Choice Scenes}) = 0 $$

* **시작 점수**: 모든 작품 공통 **3점** (방황하는 미완의 영혼)
* **선택지 델타 규칙**:
  * 올바른 결단 및 도덕적 각성: **`+1`**
  * 유혹에의 굴복, 나태, 독재, 회피: **`-1`**
  * 전환 씬 및 중립적 관찰: **`0`** (점수 변동 없음)

---

### 2.2 3대 난이도별 스펙 테이블

| 난이도 등급 | 권장 독서층 | 총 막 수 | 선택지 씬 수 | 전환 씬 수 | 시작 점수 | **최대 점수 (Max)** | 🏆 진엔딩 (≥75~80%) | 🎖️ 정석엔딩 (50~70%) | 🌱 보통엔딩 (<50%) |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| **튜토리얼 / 쉬움 🟢** | **초등 도서 권장** | **10막** | 7개 | 3개 | 3점 | **10점** (3+7) | **8 ~ 10점** | 5 ~ 7점 | 0 ~ 4점 |
| **중간 🟡** | **중고등 도서 권장** | **15막** | 11개 | 4개 | 3점 | **14점** (3+11) | **11 ~ 14점** | 7 ~ 10점 | 0 ~ 6점 |
| **어려움 🔴** | **성인 문학 권장** | **20막** | 14개 | 6개 | 3점 | **17점** (3+14) | **13 ~ 17점** | 8 ~ 12점 | 0 ~ 7점 |

## 3. 작품별 메타데이터 매핑 규격

### 3.1 튜토리얼 / 초급 🟢 (10막 완결 · Max 10점)
* **《흥부놀부전》** (한국 고전): ♧ 선행의 씨앗 (0~10점)
* **《제임스와 슈퍼 복숭아》** (로알드 달): ✦ 경이와 용기 (0~10점)
* **《찰리와 초콜릿 공장》** (로알드 달): 🍫 순수함의 황금 (0~10점)
* **《마틸다》** (로알드 달): 📖 지혜와 정의 (0~10점)

### 3.2 중간 🟡 (15막 완결 · Max 14점)
* **《데미안》** (헤르만 헤세): ☥ 내면의 각성 (0~14점, 진엔딩: 11점)
* **《동물농장》** (조지 오웰): 🚩 비판적 양심 (0~14점, 진엔딩: 11점)
* **《1984》** (조지 오웰): 👁️ 인간성의 존엄 (0~14점, 진엔딩: 11점)
* **《수레바퀴 아래서》** (헤르만 헤세): 🌿 영혼의 순수성 (0~14점, 진엔딩: 11점)

### 3.3 어려움 🔴 (20막 대서사시 · Max 17점)
* **《단테의 신곡: 지옥·연옥·천국》** (단테 알리기에리): ☀️ 신성한 은총의 빛 (0~17점, 진엔딩: 13점)
* **《차라투스트라는 이렇게 말했다》** (프리드리히 니체): 🦅 위버멘쉬의 불꽃 (0~17점, 진엔딩: 13점)

## 4. 엔진 런타임 구현 사양 (Engine Implementation)

### 4.1 런타임 맥스 점수 판별 함수
```javascript
function getMaxScoreForPack(pack) {
  if (!pack) return 10;
  if (pack.scenes.length >= 20) return 17; // 고급: 20막
  if (pack.scenes.length >= 15) return 14; // 중급: 15막
  return 10;                               // 초급/튜토리얼: 10막
}
```

### 4.2 인게임 게이지 바 비율 계산
$$ \text{Bar Percentage (\%)} = \min\left(100, \operatorname{round}\left(\frac{\text{metricValue}}{\text{maxScore}} \times 100\right)\right) $$
* UI 출력: `${metricValue} / ${maxScore}` (예: 동물농장 시작 시 `3 / 14`, 단테 신곡 시작 시 `3 / 17`)

## 5. 향후 신규 팩 제작 시 필수 준수 수칙 (Guidelines)

1. **신규 팩 기획 시 임의의 점수 부여 금지**: 선택지 분기 시 반드시 `delta: 1` 또는 `delta: -1`만 사용한다.
2. **막 수에 따른 씬 템플릿 준수**:
   * 10막 기획 시: 선택 씬 7개 + 전환 씬 3개
   * 15막 기획 시: 선택 씬 11개 + 전환 씬 4개
   * 20막 기획 시: 선택 씬 14개 + 전환 씬 6개
3. **엔딩 프로필 명시**: 진엔딩 컷오프를 반드시 상한선의 약 75~80%에 해당하는 점수로 `3_scene.yaml`과 `1-1_story_structure.md`에 기재한다.
