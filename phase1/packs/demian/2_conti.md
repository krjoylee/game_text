## 씬 1: 두 개의 세계 (`act01_scene_01`)

### 1. 카드 프레임 아스키 아트 (14줄)
```
                                                                          
              ┌────────────────────────┐                                  
              │   밝고 경건한 부모의 집 │                                  
              └───────────┬────────────┘                                  
                          │                                               
             싱클레어 [♧] │         프란츠 크로머 [☠]                     
           \"죄책감과 공포\"│        \"사과 훔친 걸 다 불어버릴까?\"          
            ┌───────────┐ │        ┌───────────────────┐                  
            │ 따뜻한 질서│ │        │  어두운 골목길    │                  
            └───────────┘ │        └───────────────────┘                  
                          │                                               
         ═════════════════╧══════════════════════                         
               두 세계의 경계에 서서 공포에 떨고 있는 싱클레어           
                                                                          
```

### 2. 대화문 (구어체 / 문학체)
* **프란츠 크로머**: "사과 두 개 훔쳤다고 했지? 그 과수원 주인이 도둑을 찾고 있던데?"
* **싱클레어**: "거짓말이야... 제발 부탁이야, 아무에게도 말하지 마!"
* **프란츠 크로머**: "그럼 내일까지 2마르크를 가져와. 안 그러면 경찰에 넘길 테니!"

### 3. 선택지
1. **자신의 비겁함을 직시하며 고통 속에서 해결책을 찾는다** (`자아의 빛 +1`)
2. **공포에 질려 크로머의 요구에 맹목적으로 굴복한다** (`자아의 빛 -1`)

## 씬 8: 내면의 거울 (`act08_scene_01`, 엔딩)

### 1. 카드 프레임 아스키 아트 (14줄)
```
                                                                          
               포탄이 멎은 고요한 야전 병원                               
             ┌──────────────────────────────────┐                         
             │ 막스 데미안 [✦] : 마지막 숨을 거두며                       │                         
             │ \"싱클레어, 네 안을 들여다봐. 내가 그곳에 있을 거야\"      │                         
             └─────────────────┬────────────────┘                         
                               │ 마지막 입맞춤                            
             싱클레어 [♧] ────▼ 거울을 들여다보다                         
                                                                          
             ┌──────────────────────────────────┐                         
             │ 거울 속에 비친 내 얼굴...        │                         
             │ 그는 이제 완전히 나와 하나가 되었다│                         
             └──────────────────────────────────┘                         
         ════════════════════════════════════════                         
                                                                          
```

### 2. 대화문
* **막스 데미안**: "싱클레어, 언젠가 내가 필요해지면 네 안을 들여다봐. 내가 그곳에 살고 있을 테니."
* **막스 데미안**: "에바 부인께서 네게 전해달라고 하신 마지막 키스야..."
* **싱클레어**: "거울을 본다. 그곳에는 더 이상 나약한 소년이 아닌, 데미안과 완전히 하나가 된 내가 서 있다."

### 3. 선택지 (엔딩)
1. **내면 깊은 곳에서 살아 숨 쉬는 데미안을 온전히 포용하며 미소 짓는다** (`자아의 빛 +2`, `ending`으로 이동)
2. **슬픔과 고독 속에서 흔들리며 가만히 눈을 감는다** (`자아의 빛 +0`, `ending`으로 이동)
